OpenAlex 조회 한도 늘리기 (선택. 안 넣어도 동작합니다)

OpenAlex는 키 없이 하루 100회까지 조회됩니다. 이 툴은 Crossref·RISS로 못 찾은 문헌에만 OpenAlex를 부르므로 보통은 넉넉하지만, 많이 쓰시면 무료 키를 받아 넣으세요. 하루 1,000회로 늘어납니다. 한도를 넘겨도 나머지 조회처로 계속 검증하며, 화면 위에 알려 드립니다.

받는 곳: openalex.org/pricing — 이메일로 가입하면 무료 키가 나옵니다. 키는 이 컴퓨터에만 저장되고 어디로도 전송되지 않습니다.

판정 읽는 법 · 확인됨 제목이 거의 같고 연도가 맞으며 저자나 게재지가 뒷받침됨   검토 필요 후보는 있으나 연도·저자·게재지 중 어긋난 것이 있음   확인 불가 조회한 곳에서 일치 항목을 찾지 못함   검증 제외 법령 등 서지 DB 대상이 아님
심사에 쓸 때 · ‘확인됨’이 아닌 항목은 모두 사람이 직접 봐야 합니다. ‘확인 불가’가 곧 허위라는 뜻은 아닙니다. 단행본·기관보고서·학술대회 발표문·오래된 국내 문헌은 DB 수록률이 낮습니다. 표의 검색 링크로 확인하세요.
주의 표시 · ‘DOI 제목 불일치’와 ‘DOI 없음’은 지어낸 문헌에서 자주 나타납니다. ‘연도 불일치’는 재발행본을 인용했거나 연도를 잘못 적은 경우입니다. ‘중복 기재’는 같은 문헌이 목록에 두 번 이상 올라온 경우입니다.
이 프로그램은 Crossref·OpenAlex·RISS 공개 정보만 조회하며 API 키나 계정이 필요 없습니다. ‘확인됨’이어도 권호와 페이지까지 맞는지는 원문에서 보셔야 합니다.
