# 참고문헌 실존 확인

논문의 참고문헌이 **실제로 존재하는 문헌인지** 확인하고, 원문으로 가는 링크(RISS 원문보기 · DOI · 무료 PDF)를 붙여 주는 프로그램입니다.
AI가 지어낸 가짜 참고문헌, 연도·저자 오기, DOI 오기, 중복 기재를 걸러내는 데 씁니다.

논문 심사에 쓰는 도구라 판정을 보수적으로 합니다. 가짜를 '확인됨'으로 통과시키는 쪽이 위험하고, 진짜를 '확인 불가'로 넘기는 쪽은 사람이 한 번 더 보면 되는 실수이기 때문입니다.

## 내려받기

[**최신 버전 내려받기 (Releases)**](../../releases/latest)

설치 과정은 없습니다. `참고문헌 실존 확인.exe` 하나만 내려받아 더블클릭하면 됩니다. USB에 담아 다녀도 됩니다.

윈도우 10/11 64비트에서 동작합니다. 파이썬을 따로 설치할 필요가 없습니다.

> 처음 실행할 때 "Windows의 PC 보호"라는 파란 창이 뜰 수 있습니다.
> 개발자 서명이 없는 프로그램에 윈도우가 붙이는 일반적인 경고입니다.
> **[추가 정보]** → **[실행]** 을 누르면 됩니다. 한 번 허용하면 다음부터는 뜨지 않습니다.

## 쓰는 순서

1. 논문 파일을 창에 끌어다 놓습니다. **PDF · DOCX · HWPX · TXT** 를 읽습니다.
   구버전 `.hwp` 는 한글에서 `.hwpx` 나 PDF로 저장한 뒤 넣으세요.
   참고문헌 목록만 있다면 '텍스트 붙여넣기' 탭을 쓰면 됩니다.
2. 추출된 목록을 확인합니다. 한 줄이 한 문헌이며, 잘못 나뉜 항목은 그 자리에서 고칠 수 있습니다.
3. **실존 여부 확인 시작** 을 누릅니다. 결과가 나오는 대로 표에 채워지고, 끝나면 엑셀로 저장할 수 있습니다.
4. 맨 아래 **APA 정렬 목록** 에서 정리된 참고문헌을 복사해 논문에 붙여넣습니다.

## 판정

| 판정 | 뜻 | 해야 할 일 |
|---|---|---|
| 확인됨 | 제목이 거의 같고 연도가 맞으며 저자나 게재지가 뒷받침됨 | 없음 |
| 검토 필요 | 후보는 있으나 연도·저자·게재지 중 어긋난 것이 있음 | 원문 링크를 열어 대조 |
| 확인 불가 | 조회한 곳에서 일치 항목을 찾지 못함 | 검색 링크로 직접 확인 |
| 검증 제외 | 법령·고시 등 서지 DB 대상이 아님 | 국가법령정보센터에서 확인 |

'확인됨'이 아닌 항목은 모두 사람이 직접 봐야 합니다. 결과 위의 요약 줄에 그 건수가 나옵니다.

'확인 불가'가 곧 가짜라는 뜻은 아닙니다. 단행본·기관보고서·학술대회 발표문·오래된 국내 문헌은 DB 수록률이 낮습니다.

### 주의 표시

| 표시 | 뜻 |
|---|---|
| DOI 제목 불일치 | 적힌 DOI는 실재하지만 다른 논문의 것입니다. 지어낸 문헌에서 자주 나옵니다 |
| DOI 없음 | 적힌 DOI가 Crossref에 등록되어 있지 않습니다 |
| 연도 불일치 | 재발행본을 인용했거나 연도를 잘못 적었습니다 |
| 저자 불일치 / 게재지 불일치 | 제목은 맞는데 저자나 학술지가 다릅니다 |
| 중복 기재 | 같은 문헌이 목록에 두 번 이상 올라와 있습니다 |

## APA 정렬 목록

제1저자 기준으로 국문(가나다)을 먼저, 영문(ABC)을 뒤에 놓습니다. 확인되지 않은 항목은 빨간색입니다.
'서식 그대로 복사'로 한글·워드에 붙여넣으면 빨간색이 따라갑니다.
번호 형식(없음 / `(1)` / `[1]` / `1.` / `1)`)은 학교마다 다르므로 복사 전에 고를 수 있습니다.

## 어디를 조회하나

| 대상 | 조회처 |
|---|---|
| 국문 문헌 | RISS(국내학술논문·학위논문·단행본·연구보고서) + Crossref + OpenAlex |
| 영문 문헌 | Crossref + OpenAlex, 일치가 없으면 RISS까지 |
| 영문으로 인용된 국내 문헌 | Korea·Seoul·KOSHA 등이 있으면 RISS 국내 컬렉션도 함께 |
| DOI가 적힌 문헌 | Crossref에 DOI를 직접 조회해 등록 제목과 대조 |
| 웹 자료 | 적힌 주소에 실제로 접속되는지 확인 |

**API 키나 계정이 필요 없습니다.** 모두 공개된 정보만 조회하며, 실행할 때 AI 모델을 부르지 않습니다.
대조는 문자열 유사도 계산으로 합니다.

문서 내용을 통째로 외부에 보내지 않습니다. 참고문헌의 제목·저자 같은 검색어만 조회에 씁니다.
조회 결과는 `%LOCALAPPDATA%\RefCheck\cache` 에 30일간 보관해 같은 논문을 다시 검사하면 빨라집니다.

## 소스에서 실행하기

[uv](https://docs.astral.sh/uv/) 가 필요합니다.

```bash
uv venv --python 3.13 .venv
uv pip install --python .venv -r requirements.txt
.venv/Scripts/python app.py
```

윈도우에서는 `실행.bat` 을 더블클릭해도 됩니다. 배포용 exe를 다시 만들려면 `빌드.bat` 을 실행합니다.

## 한계

- 스캔한 이미지 PDF는 글자가 없어 읽지 못합니다. 텍스트가 들어 있는 PDF를 쓰세요.
- RISS는 공개 API가 없어 검색 결과 화면을 읽습니다. RISS가 화면 구조를 바꾸면 `refcheck/riss.py` 를 손봐야 합니다.
- OpenAlex는 무료 일일 조회 한도가 있습니다. 한도를 넘기면 그 조회처를 빼고 판정하며 화면 위에 알려 줍니다.
- '확인됨'이어도 권호와 페이지까지 맞는지는 원문에서 확인해야 합니다.
